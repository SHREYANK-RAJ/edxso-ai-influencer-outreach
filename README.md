# Automated Micro-Influencer Outreach System

A complete AI-powered system that discovers relevant micro-influencers, checks whether they match a brand's requirements, enriches their profiles, creates personalized outreach messages, and tracks the outreach process.

The system is designed for the **Technology & Gadgets niche in India**.
